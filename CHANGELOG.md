# Изменения Reqmas

## 0.3.0 — подготовка к GitHub и сборки для трёх ОС

- Отдельные конфигурации Tauri: Windows NSIS, macOS app/DMG, Linux DEB/AppImage.
- GitHub Actions: проверки frontend/Rust и сборки Windows x64, macOS universal, Linux x64 на Ubuntu 22.04.
- macOS/Linux: AES-256-GCM для известных секретов, ключ в macOS Keychain или Linux Secret Service; Windows DPAPI сохранён.
- OAuth PKCE открывает системный браузер также в macOS/Linux, не блокируя callback listener.
- Лицензия MIT, инструкции сборки и публикации, исключение локальных данных/ключей/артефактов из Git.
- macOS/Linux требуют выполнения CI и проверки на реальной ОС; подготовка на Windows сама по себе не подтверждает их runtime-совместимость.

## 0.2.2 — 2026-10-09

- Терминальное оформление: почти чёрный фон, зелёные акценты, моноширинная типографика, тонкие рамки, компактные панели и prompt-иконка. Палитра применяется к редактору, Response/Tree/Compare, навигации, Runner, журналу и диалогам.
- Light и System сохраняются; светлый вариант использует ту же геометрию. Google Fonts заменены локальными Cascadia/Consolas с monospace fallback, оформление работает без загрузки шрифтов.
- Сохранена различимая подсветка JSON, согласованы метрики курсора и подсветки редактора. Добавлены контрастные focus-состояния и переносы панели действий; анимация индикатора отключается при reduced motion.
- Проверены light/dark, окна 650/700 px, JSON editor, Response, Tree, Runner и settings; исходный browser workspace восстановлен и точно сверён. Production frontend, ESLint, Windows GUI EXE и NSIS собраны, новое desktop-окно осмотрено.

## 0.2.1 — 2026-10-09

- **Сохранение данных:** повторное удаление запроса из History больше не создаёт дубликаты в корзине; прежние дубликаты исправляются при загрузке. Сохранение и закрытие последней вкладки открывает актуальный сохранённый запрос. Документ проверяется перед записью, размер черновиков при загрузке учитывается один раз.
- **Импорт и экспорт:** Postman/OpenAPI проверяют лимиты переменных, запросов, папок и развёрнутых данных. Импорты Postman, OpenAPI и cURL проверяют общий workspace до изменения данных. Ошибки остаются в диалоге; слишком большой экспорт отклоняется до скачивания.
- **OAuth:** токены разных аккаунтов с одинаковым Client ID изолированы. Обновления одного rotating refresh token сериализованы даже для разных снимков access token. Новый PKCE-вход не наследует refresh token прежнего аккаунта; поздний ответ не заменяет вручную изменённые credentials. Исправлено кодирование Client ID/Secret для OAuth Basic.
- **Несколько экземпляров:** новая desktop-версия удерживает системную блокировку workspace до выхода. Вторая копия показывает сообщение до открытия данных. После закрытия первой копии вторую нужно перезапустить; старые версии эту блокировку не поддерживают.
- **Интерфейс:** дублирование окружения сбрасывает подтверждение удаления, cookie с expiry=0 показывается как истёкший, пустой HTTP body отображается без ошибочного предупреждения о JSON.
- **Проверки:** повторный аудит интерфейса на локальном API, 235 JavaScript-тестов, 31 Rust-тест, ESLint и strict Clippy. Подробности и границы проверки — в AUDIT.md.

## 0.2.0 — 2026-10-09

- **Навигация:** дерево вложенных папок с неявными родителями, сохранение состояния сворачивания и раскрытие совпадений поиска. Перенос и порядок запросов/коллекций меняются перетаскиванием или кнопками ⋯. Горячие клавиши Ctrl+Enter, Ctrl+S и Ctrl+K приостанавливаются при открытых диалогах.
- **Хранилище:** desktop workspace, черновики и настройки перенесены в SQLite с миграцией прежних данных WebView. Windows DPAPI защищает отмеченные Secret значения, известные credentials и приватные ключи для текущего пользователя. Экспорт по умолчанию исключает такие значения; для переноса credentials доступен Include secrets. Весь workspace целиком не шифруется, данные raw body, datasets и файлов требуют отдельного внимания.
- **Runner:** сохранённые сценарии с порядком запросов, настройками запуска и CSV/JSON данными. Retry failed повторяет неуспешные задачи с исходными снимками запросов и строками dataset; отменённые и невыполненные задачи исключаются. Окружение и наследуемая авторизация используются из текущего workspace. Сценарии входят в backup.
- **Соединение:** desktop HTTP/HTTPS proxy, собственные доверенные CA в PEM и клиентские сертификаты mTLS. Проверка сертификатов сохраняется; connection settings применяются также к OAuth token endpoint и Runner. Body HTTP ответа ограничен 100 MiB.
- **OAuth:** Authorization Code + PKCE с системным браузером, S256, state и локальным callback в desktop. Автоматическое обновление истёкшего токена перед отправкой использует refresh token либо Client Credentials; параллельные обновления одного account сериализованы. Browser mode поддерживает готовые токены, Client Credentials и refresh с учётом CORS.
- **Установка и обслуживание:** NSIS-установщик для текущего пользователя с автоматической установкой WebView2 при необходимости, отдельный EXE и обновлённые инструкции переноса. До 10 автоматических копий SQLite с интервалом не меньше минуты при обычных изменениях; перед восстановлением создаётся дополнительный снимок. Закрытие окна ждёт сохранения и остаётся заблокированным при ошибке записи.
- **Подписанные обновления:** настройки HTTPS manifest и доверенного публичного ключа, проверка подписи с привязанной версией, просмотр release notes и подтверждение установки; скачивание ограничено 100 MiB. Хостинг и ключи пока не настроены. Добавлены UPDATES.md, конфигурация подписанной сборки и генератор manifest с проверкой артефакта/сигнатуры/версии без перезаписи существующего файла.
- **Надёжность:** последовательная очередь сохранения, проверка данных перед загрузкой и восстановлением, блокировка запуска при ошибке миграции вместо перезаписи базы, очистка прежних записей localStorage только после успешного переноса. Исправлено зависание кнопки закрытия: main-окну разрешена команда destroy, выполняемая после сохранения. Добавлены регрессионные проверки для дерева и перемещений, desktop-хранилища, закрытия окна и генератора manifest.
